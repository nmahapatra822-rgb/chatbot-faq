# 🤖 FAQ Chatbot

A simple and interactive FAQ Chatbot built using **Python** and **Streamlit**. The chatbot answers user queries from a local FAQ database stored in a CSV file.

## 🚀 Features

- Interactive chat interface
- Modern Streamlit UI
- Reads FAQs from a CSV file
- Instant responses
- Chat history
- Clear Chat option
- Offline (No API required)

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- HTML/CSS
- CSV

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/nmahapatra822-rgb/chatbot-faq.git
```

Go to the project folder:

```bash
cd chatbot-faq
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
